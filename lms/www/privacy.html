Kebijakan Privasi

Terakhir diperbarui: 23 Desember 2024

1 Pendahuluan

Ablarsy Academy berkomitmen untuk melindungi privasi Anda. Kebijakan ini menjelaskan bagaimana kami mengumpulkan, menggunakan, dan melindungi data pribadi Anda.

2 Data yang Kami Kumpulkan
Informasi Akun
  • Nama lengkap, email, username
  • Password (terenkripsi)
  • Foto profil & cover image (opsional)
  • Negara dan zona waktu
Informasi Profil Tambahan
  • Kategori pengguna (Student, Employee, dll)
  • Bio/deskripsi diri
  • LinkedIn, GitHub, Medium (opsional)
  • Status pencarian kerja
Informasi Pembelajaran
  • Progress kursus (persentase)
  • Lesson terakhir yang diakses
  • Nilai quiz dan sertifikat
  • Catatan pribadi
Informasi Pembayaran
  • Nama & alamat penagihan
  • Order ID dan Transaction ID (Midtrans)
  • Metode pembayaran (Bank/E-Wallet)
Catatan: Kami TIDAK menyimpan informasi kartu kredit. Semua proses pembayaran dihandel oleh Midtrans.
Informasi Referral & Payout
  • Kode referral unik
  • Metode payout (GoPay, DANA, OVO, Bank Transfer)
  • Nomor telepon e-wallet / rekening bank
3 Penggunaan Data

Kami menggunakan data Anda untuk:

Tujuan Dasar Hukum

Memproses pembayaran Pelaksanaan kontrak
Melacak progress pembelajaran Pelaksanaan kontrak
Menerbitkan sertifikat Pelaksanaan kontrak
Mengelola program referral Pelaksanaan kontrak
Mengirim notifikasi kursus Kepentingan sah
Mencegah penipuan Kewajiban hukum
4 Berbagi Data dengan Pihak Ketiga

Kami dapat berbagi data dengan:

  • Midtrans – Payment gateway untuk memproses pembayaran
  • Penyedia Email – Untuk notifikasi transaksional
  • Google Meet – Untuk live class
  • Cloud Server – Tempat data disimpan
Kami TIDAK menjual data pribadi Anda kepada pihak ketiga.
5 Penyimpanan Data

Data Anda disimpan di server yang berlokasi di Indonesia atau Asia Tenggara.

Langkah Keamanan
  • Enkripsi SSL/TLS untuk transfer data
  • Enkripsi password dengan hash yang aman
  • Akses terbatas untuk personel berwenang
  • Backup data secara berkala
  • Firewall dan proteksi DDoS
Retensi Data
  • Akun aktif: Selama akun aktif
  • Akun tidak aktif: Diarsipkan setelah 2 tahun
  • Data pembayaran: Minimal 5 tahun (kewajiban pajak)
  • Sertifikat: Permanen untuk verifikasi
6 Cookies

Platform kami menggunakan:

  • Cookies sesi – untuk menjaga status login
  • Cookies preferensi – untuk menyimpan pengaturan tampilan

Anda dapat mengelola cookies melalui pengaturan browser.
